# Ownership decision and provenance groundwork

The standalone `BookMembershipDecision.kt` is not connected to folder removal, UI, persistence or library visibility. It is not authority to delete source documents or database rows. Exclusions in its model now use grant plus directory identity, consistent with the scanner's exclusion groundwork.

The scanner records positive SAF observations using opaque provider document IDs, grant URI and observed directory routes in Room v9. New scanner origins and routes are recorded only when identity and route validation succeeds. A name/size collision is explicitly unresolved, not proof that two documents or library rows are identical. Existing and manually added rows are not assigned an invented scanner origin. Historical observations do not prove the full set of current routes or owners, and the absence of an observation proves nothing about ownership.

The decision model separates document identity from filename and size, and fails closed for incomplete, stale, shared, ambiguous or internally inconsistent evidence. It can only nominate reversible visibility changes when its inputs assert complete, consistent, affected membership. Those inputs do not establish completeness, freshness, independence from manual ownership, or provider atomicity. Current scanner traversal may omit alternative paths through multi-parent directories, so its stored observations cannot yet establish exclusivity. Folder removal remains disabled.
